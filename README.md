# 🛒 EcomX – Full-Stack E-Commerce Web Application

> **EcomX** is a full-featured e-commerce web application built using Node.js, Express, MongoDB, and EJS. Users can browse products, add to cart, register accounts, and place orders.

---

## ✨ Features

- 👤 User registration and login
- 🛍️ Product listing and details pages
- 🛒 Add to cart & cart management
- 📦 Place orders
- 🧑‍💼 Admin panel for managing products
- 🔐 Authentication & session management
- 📁 MVC-style project structure
- 🌐 Server-side rendering using EJS
